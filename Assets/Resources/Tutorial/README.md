# チュートリアル台本の編集ガイド

このフォルダの `TutorialScenario.asset` が、チュートリアル全5局の台本です。
Project ウィンドウで選択すると Inspector に中身が並びます。

---

## どこを触れば何が変わるか

Inspector の見出しに記号が付いています。

| 記号 | 意味 |
| :--- | :--- |
| **● セリフを変える** | **自由に書き換えてOK。** 他に影響しません |
| **■ 牌／状況を変える** | 影響を理解していれば可。牌の並びや進行が変わります |
| **▲ 数値注意** | **HP収支に連鎖します。触る前に下の表を必ず読んでください** |

### セリフの構造

`Rounds` → 各局 → `● セリフを変える` の下にまとまっています。

- **Text** … 本文
- **Speaker** … 話者。立ち絵が切り替わります
  - `Enemy` … 対戦相手の女の子
  - `Senpai` … あずにゃん先輩
  - `System` … 地の文・ルール説明

セリフの出る場面は項目名で分かれています。

| 項目 | 出る場面 |
| :--- | :--- |
| `introLines` | 局の始まり |
| `onHandFilledLines` | 手牌13枚がそろった直後 |
| `beforeBetLines` | 手牌決定後・賭け金の前 |
| `onBattleStartLines` | 対局開始直後 |
| `beforeManualDiscardLines` | 自動打牌が終わり、自分で打つ直前 |
| `outroLines` | 結末演出のあと |
| `endingLines` | 全5局が終わったあと（アセットの一番下） |

## ▲ 数値を変える前に必ず読むこと

**賭け金・飜数・流局ダメージは、全局のHPに連鎖します。**
1つ変えると以降が全部ずれ、**途中で誰かが死ぬと進行不能**になります。

### 血の流れ

賭け金は**確定した時点で両者の血から引かれ**、場に積まれます。
決着時の増減はこれとは別に `GameRules` の式で決まります。

```
勝者が得る額 = 勝者自身の賭け金 × 勝者の役の倍率
敗者が失う額 = 敗者自身の賭け金 × 勝者の役の倍率（単騎で上がられたら2倍）

倍率: 満貫1 / 跳満1.5 / 倍満2 / 三倍満3 / 役満4 / ダブル役満8
```

満貫（1倍）は払った賭け金と同額が戻るだけなので、**勝っても差し引き0**です。
流局では決着せず、賭け金は次の局へ積み増されます。

```
開始                                              P20000 / E20000
第1局 賭け金2000ずつ引かれる                      P18000 / E18000
      自分ロン 清一色6飜=跳満1.5倍
        自分 +3000 / 相手 -3000                   P21000 / E15000
第2局 賭け金600ずつ                               P20400 / E14400
      流局（場はそのまま持ち越し）                P20400 / E14400
第3局 同額600が自動で引かれ、賭け金は各1200        P19800 / E13800
      相手ロン 四暗刻単騎13飜=役満4倍・単騎
        相手 +4800 / 自分 -9600                   P10200 / E18600
第4局 能力コスト -12700（手牌フェイズ）           P10200 / E 5900
      賭け金1000ずつ                              P 9200 / E 4900
      自分ロン 対々和+混一色5飜=満貫1倍
        自分 +1000 / 相手 -1000                   P10200 / E 3900
第5局 賭け金1000ずつ                              P 9200 / E 2900
      自分ロン 純正九蓮宝燈26飜=ダブル役満8倍
        自分 +8000 / 相手 -8000（残2900で死亡）   P17200 / E    0（決着）
```

### 守らないと壊れる条件

- **第3局で自分が死なないこと**（単騎の2倍が効くので損失が跳ね上がる）
- **第4局の前に相手が能力コスト12700を払えること**
- **賭け金の支払いで誰も死なないこと**（第4局・第5局は相手の血が薄い）
- **第4局のあとも相手が生き残り、第5局で死ぬこと**
- **全局とも満貫以上**（「満貫手以下では開始できない」制約があるため）

**数値を触ったら、必ず最後まで通してプレイして確認してください。**

## 牌の指定について

`wallBaseIds` などは**牌種（0〜28）**で指定します。ドラのフラグは自動で付きます。

```
0-8   萬子の1〜9
9-17  筒子の1〜9
18-26 索子の1〜9
27    東
28    西      ※字牌はこの2種類のみ
```

`manganHandBaseIds`（自動で組まれる13枚）は、
**`wallBaseIds` に含まれる牌だけ**で構成してください。含まれない牌を書くと組めません。
