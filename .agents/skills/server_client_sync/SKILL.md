# サーバーとクライアントのルールのズレを防ぐための確認事項

ゲームルールの変更（新しい役を追加する、スキルのコストを変えるなど）を行う際は、以下の点に注意して開発を進めてください。

## 重要な意識・チェックポイント
* **「Python側の数値を直すだけでなく、Unity側の `GameRules.cs` （または関連するロジックや定数）もセットで直したか？」**という確認が絶対に必要になります。
* 通信量削減のため、Unity側でも一部のルールやマスタデータを保持している（二重管理している）設計になっています。
* この「サーバーとクライアントのルールのズレ」は非常によくあるバグの温床になります。
* レビューを依頼する前に**「両方（Python/Unity）の定数・計算ロジックが一致しているか？」**を必ずセルフチェック（見直し）する癖をつけること。これにより、手戻りを大きく防ぐことができます。

タスクを完了する前やレビュー（確認）をユーザーに依頼する前に、必ずこのセルフチェックを実施してください。
