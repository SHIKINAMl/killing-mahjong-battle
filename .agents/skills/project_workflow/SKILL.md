# Project Workflow (プロジェクト進行の3ステップ)

プロジェクトに関する依頼を受けた際や、新しいタスク群に取り組む際は、常に以下の3つの流れを意識して行動してください。

1. **プロジェクトコードのドキュメント化**
   プロジェクトのコードや現状の仕様を読み解き、構成や概要を書き起こした Markdown ファイル（.md）を作成してください。

2. **タスクの分割**
   上記のドキュメントをもとに、必要な作業を細かく分割し、タスク一覧用の Markdown ファイル（.md）を作成してください。

3. **役割分担の明確化（人間・AI・スクリプト）**
   分割したタスクについて、それぞれ誰が担当するかを以下の3つに明確に分けて記載してください。
   - 人間（ユーザー）がやること
   - AI（あなた）がやること
   - スクリプト（自動化処理）がやること

このフローを常に意識し、プロジェクトを体系的かつ効率的に進行させることが求められます。
