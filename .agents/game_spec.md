# Killing Mahjong Battle 基本仕様

## 概要
- **ジャンル**: 1vs1 の対戦麻雀ゲーム
- **アーキテクチャ**: 
  - クライアント: Unity (C#)
  - サーバー: Python (`mahjong_engine` を使用したWebSocketサーバー)
  
## ゲームの流れ (フェイズ)
ゲームは主に以下のフェイズ（`RoundStatus`）で進行する。
1. **Betting (掛け金フェイズ)**
   - 対局開始前に、プレイヤーが掛け金（Bet）を決定する。
   - お互いの初期HP（20000など）から掛け金をやり取りし、勝敗によってHPが増減する。
   - スマホ風のUI（PlayerInfoUI）が画面中央に大きく表示され、掛け金を選択・決定する。
2. **Dealing (配牌フェイズ)**
   - サーバーから配牌情報が送られ、アニメーションとともに牌が配られる。
3. **Hand Selection (手牌選択 / マリガンフェイズ)**
   - 配牌後、特定の手牌を交換できる（マリガン）スキルが存在する。
   - プレイヤーは「この手牌で決定しますか？」という確認を経て手牌を確定する。
4. **ゲーム進行**
   - ツモ・打牌が進行。
   - 役の判定、ドラの確認などが行われる。
   - ロン・ツモ和了時に演出が入り、ダメージ計算が行われる。

## 特殊なシステム
- **HPシステム**: 通常の麻雀の点数（点棒）だけでなく、対戦格闘ゲームのような「HP」が設定されている。
- **スキルシステム**: プレイヤーは特殊な能力（牌交換など）を使うことができる。
- **ダイナミックなUI演出**: 
  - `PlayerInfoUI`: プレイヤーの情報を表示するスマホ型UI。状況に応じて画面中央にズームしたり、他UIより手前に表示されたりする。
  - キャラクターの表情やセリフ（DialogueUI）、揺れアニメーション（FloatingAnimator）などの演出が豊富。
