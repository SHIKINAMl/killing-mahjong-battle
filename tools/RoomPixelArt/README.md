# 部屋の個別ドット素材

壁・窓・本棚・本・机・床など、元の背景33部品を個別のPNGに変換しています。
正本は `parts.json` の元寸法・色。シーンの各オブジェクトに直接Spriteを割り当て、
3つの背景レイヤーとRectTransformの位置・サイズを維持します。
本12冊は定義された高さ・間隔で棚板の上面に揃えて配置します。
女の子・看板・メニュー文字には適用しません。

## 再生成

このフォルダーで `npm ci --ignore-scripts`、`npm run generate`。
Unityで `Tools > UI > 部屋の個別ドット素材を配置` を実行します。
現在の部屋シーンを保存するので、別の作業の未保存変更がある場合は先に確認してください。

通常のPNGは元の矩形・色に狭い濃淡を付け、2ピクセル単位に減色・ディザ処理して黒縁を付けます。
窓明かりとランプの光は黒縁を付けず、透過ドットのマスクを使い、Image側の色・明滅を維持します。
インポート設定はPoint、非圧縮、MipMapなし、FullRectです。

使用ツール: [Image-to-Pixel](https://github.com/Tezumie/Image-to-Pixel) 3.1.0。
同梱ライセンスは `LICENSE.image-to-pixel.txt`。既存部品の変換であり、AI画像生成は使用していません。
