ゲームのコード・シーン・metaは変更しない。画像生成ツールは使わない。

## 再生成

このフォルダーで次を実行する（Node.js 18以上）。

```powershell
npm ci --ignore-scripts
npm run generate
npm run verify
```

`generate` は `Assets/Resources/UI/Cutin/gothic_band.png` を上書きし、比較画像と合成見本を
`C:/Unity/km-docs/screenshots/20261020/cutin_pixel_bg/v4_bat_blood/` に出す。
別の見本出力先にする場合は `CUTIN_REVIEW_DIR` に絶対パスを設定する。
今回の実行ではネットワーク取得をせず、同一バージョンの依存一式を `RoomPixelArt/node_modules/` からコピーした。
`node_modules/` はGit対象外。バージョンと完全性情報は `package-lock.json` に固定。

## 手法

1. `gothic_band_before.png` は着手時の本体の無加工コピー。SHA-256:
   `5b57e698b824f3e7cef0bbdefd9a77766c92d12ed0835097269076cce471d0f3`。
   再生成のたびに現在の本体を入力にしないため、何度実行しても柄が累積しない。
2. 元画像をNearestで800×600へ拡大。両端の窓の範囲を元の布の縦ひだで埋め戻し、
   2倍解像度の整数座標に多角形で雫・コウモリを描く。Asepriteは使っていない。
3. 部屋素材と同じ **Image-to-Pixel 3.1.0 / CPU** に通す。
   `size: 400×300, resample: box`、既存8色の `custom` パレット、距離 `oklab`、
   `dither: bayer4, strength: 0.18`、`outline: none`。
4. 変換後のRGBのうち、左右50px未満かつ斜めの外枠から15px以上離れた範囲だけを採用する。
   ほかのRGBと**全画素のalphaは元画像から直接維持**する。
   中央の夜色・ディザ・外枠を変えず、変換器の境界処理からMask形状を保護する。

原形と図形定義は `generate.mjs`、描画の補助は `art.mjs`、検算は `verify.mjs`。
Image-to-Pixelの同梱ライセンスは `LICENSE.image-to-pixel.txt`。

## 模様・パレット

- 左右2列、横24px・縦36px間隔。隣の列は縦18pxずらす。行ごとに雫とコウモリを交互にする。
- コウモリ18×10px（2倍表示36×20単位）、雫10×14px（同20×28単位）。
- 布は `#3E1522` / `#461827` / `#4E1B2C`。柄は `#4E1B2C`。
  黒い輪郭・目・光沢は付けない。明るいひだと同色になる部分は布へ溶け込ませる。
- 全体の可視色は従来と同じ8色:
  `#000000` `#160F18` `#1E0707` `#3E1522` `#461827` `#4E1B2C` `#663931` `#786E55`。
  追加の色はない。中央は従来どおり無地。
